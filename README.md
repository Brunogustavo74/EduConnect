# EduConnect

EduConnect é uma plataforma educacional desenvolvida para ajudar estudantes a organizarem seus estudos, acompanharem seu desempenho acadêmico e colaborarem com outros alunos em um único ambiente digital.

## Objetivo

O projeto busca resolver problemas reais enfrentados pelos estudantes, reunindo ferramentas essenciais para organização, aprendizagem e colaboração.

## Funcionalidades

-  Agenda inteligente para provas, trabalhos e atividades
-  Análise de desempenho acadêmico
-  Biblioteca de materiais e resumos
-  Sistema de monitoria entre alunos
-  Caderno colaborativo
-  Planejamento de estudos
-  Orientação profissional
-  Sistema de notificações e lembretes

## Tecnologias

### Frontend

- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
